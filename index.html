01
Bioinformatics · Python

Single-Cell RNA-Seq Pipeline

Built an end-to-end single-cell RNA sequencing workflow in Python using Scanpy and AnnData to analyze approximately 3,000 PBMC immune cells.

Performed quality control, cell filtering, and log-normalization, followed by PCA, Leiden clustering, and UMAP visualization. Identified marker genes to support cell-type annotation, including T cells, B cells, and monocytes.

02
Bioinformatics · Machine Learning

Breast Cancer Bone Relapse Prediction

Developed machine learning models to predict bone relapse in breast cancer using gene expression data from the GSE2034 dataset, comprising 286 samples.

Performed preprocessing, gene annotation, probe-to-gene aggregation, and feature selection, resulting in 12,548 unique genes for downstream analysis.

Developed and compared Logistic Regression, Linear SVM, and Random Forest models using repeated stratified cross-validation. The best-performing model achieved a mean cross-validated ROC-AUC of approximately 0.68.
